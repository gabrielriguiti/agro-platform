# Registros de decisão de arquitetura (ADR)

Cada decisão técnica ou de arquitetura relevante vira um ADR neste diretório, no formato de `0000-template.md`.

- Numeração sequencial, nome `NNNN-titulo-em-kebab-case.md`.
- ADR aceito não é editado; uma nova decisão cria outro ADR que o substitui e atualiza o campo Status do antigo.
- Todo change do OpenSpec lista, no `design.md`, os ADRs que gera.
